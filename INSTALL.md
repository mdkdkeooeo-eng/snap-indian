# Quick Installation Guide

## Step 1: Create Icon Files

You need to create three icon files in this folder:
- `icon16.png` (16x16 pixels)
- `icon48.png` (48x48 pixels)  
- `icon128.png` (128x128 pixels)

You can:
- Use any image editor to create simple icons
- Download free icons from sites like flaticon.com
- Use a simple colored square as a placeholder

## Step 2: Load Extension in Chrome/Edge

1. Open Chrome and go to `chrome://extensions/` (or Edge: `edge://extensions/`)
2. Enable **Developer mode** (toggle in top right)
3. Click **"Load unpacked"**
4. Select this folder (`snap bot`)
5. The extension should now appear in your extensions list

## Step 3: Pin Extension (Optional)

1. Click the puzzle piece icon in Chrome toolbar
2. Find "Snapchat Friend Filter"
3. Click the pin icon to keep it visible

## Step 4: Use the Extension

1. Go to https://web.snapchat.com
2. Log in and open "Add Friends"
3. Click the extension icon
4. Configure settings and click "Start Filtering"

That's it! The extension will automatically filter friend requests.
