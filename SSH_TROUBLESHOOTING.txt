================================================================================
SSH CONNECTION TROUBLESHOOTING FOR 207.231.108.4
================================================================================

IF SSH IS NOT WORKING, TRY THESE:

1. CHECK IF SSH IS INSTALLED
   ---------------------------
   Open PowerShell and type: ssh
   If it says "command not found", SSH is not installed on your Windows.
   
   SOLUTION: Use web browser method instead (see below)


2. TEST CONNECTION
   ---------------
   Try: ping 207.231.108.4
   If ping works, the server is reachable.
   If ping fails, check your internet connection or firewall.


3. CHECK PORT
   -----------
   SSH uses port 22. Try:
   ssh -p 22 root@207.231.108.4
   
   If port 22 is blocked, the server might use a different port.
   Ask your server admin what port to use.


4. COMMON SSH ERRORS
   ------------------
   
   "Connection refused"
   - Server might not have SSH enabled
   - Wrong port number
   - Firewall blocking connection
   
   "Permission denied"
   - Wrong password
   - Wrong username (should be "root")
   - SSH key authentication required instead of password
   
   "Host key verification failed"
   - Type: yes (to accept the host key)
   
   "Connection timed out"
   - Server might be down
   - Firewall blocking port 22
   - Wrong IP address

   a) Open your web browser

      OR: https://207.231.108.4

   Open File Explorer

8. CHECK WHAT ERROR YOU'RE GETTING

   Common messages:
   - "ssh: connect to host 207.231.108.4 port 22: Connection refused"

   Share the exact error and I can help more!


9. IF YOU HAVE ANOTHER COMPUTER
